# 개인정보 파기 대장 양식

> 동의 철회, 보존 기간 만료, 시스템 폐기 등으로 개인정보를 파기할 때 실행 내용과 확인 결과를 기록합니다.
> 파기 대장에는 대상자의 실명 대신 내부 ID를 사용해 개인정보를 최소화합니다.

| 번호 | 파기 사유 | 요청·발생일 | 파기 실행일 | 파기 범위 | 파기 방법 | 확인 결과 | 실행자 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 예1 | 동의 철회 | 2026-08-01 | 2026-08-01 | 이용자 ID 1042의 레코드 12건, 첨부 사진 7건, 계정 | DB 행 삭제(CASCADE), Storage 폴더 삭제, Auth 계정 삭제 | 삭제 후 조회 결과 0건 | 홍길동 | 철회서 접수번호 26-03 |
| 예2 | 보존 기간 만료 | 2026-01-01 | 2026-01-05 | 2020년도 프로그램일지 전체(`retention_until < 2026-01-01`) | 정기 파기 스크립트 실행, 사진 연도 폴더 삭제 | 잔존 데이터 0건 | 자동 실행 후 홍길동 확인 | 연 1회 정기 파기 |

## 기록 전 확인사항

- [ ] 데이터베이스 행, 첨부 파일, 사용자 계정, 파생 데이터, 백업 사본까지 파기 범위에 포함했는가
- [ ] 백업에서 즉시 삭제하기 어렵다면 삭제 예정 시점과 접근 제한 조치를 비고에 기록했는가
- [ ] 철회 요청자가 정보주체 본인이나 법정대리인인지 확인했는가
- [ ] 법적 보존 의무가 있는 기록과 즉시 삭제할 기록을 구분했는가
- [ ] 동의 철회 때문에 본래의 복지 서비스 이용에 불이익이 발생하지 않도록 대체 절차를 제공했는가
