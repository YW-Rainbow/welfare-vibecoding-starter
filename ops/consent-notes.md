# 동의서·처리방침 작성 시 주의점

> 동의서 전체 양식은 같은 폴더의 `consent-form-sample.md`를 사용하고,
> 여기서는 바이브코딩 앱 도입 시 자주 틀리는 지점만 짚습니다.
> 법령 기준 2026-08. 법률 자문이 아니며, 실제 사용 전 전문가 검토를 권장합니다.

## 1. 국외이전의 근거는 "동의"만이 아니다

개인정보보호법 제28조의8 제1항은 국외이전 허용 근거를 여러 개 둡니다. 실무 핵심 두 가지:

- **1호 (별도 동의)**: 생성형 AI에 개인정보를 **분석용으로 투입**하는 경우 → 이 경로가 안전.
- **3호 (계약 이행 + 공개)**: 정보주체와의 계약 체결·이행에 필요한 처리위탁·보관은,
  법정 고지사항을 **개인정보 처리방침에 공개**하면 동의 없이 가능.
  업무 클라우드에 **보관**하는 경우가 대체로 여기 해당할 여지가 큼.

→ 모든 것을 동의로 받으면 거부자마다 수기 대체 절차를 운영해야 합니다.
**보관은 3호(처리방침 공개), AI 분석은 1호(동의)**로 나누는 것을 검토하세요.
(해당 여부는 서비스 구조에 따라 판단이 갈릴 수 있으니 이 구분은 전문가 확인 대상)

## 2. "국내 리전 = 국외이전 아님"으로 단정하지 말 것

법은 "제공(**조회되는 경우 포함**)·처리위탁·보관"을 이전으로 정의합니다.
국내에 저장돼도 해외 운영·지원 인력이 조회 가능하면 이전에 해당할 수 있습니다.
- 처리방침에는 "저장: 국내(서울 리전), 다만 운영·지원 목적의 국외 접근 가능성" 같이
  사실대로 쓰는 편이 안전합니다.
- 같은 이유로, 서비스별 저장 위치가 다른 제품(예: 일부 서비스만 해외 저장)은
  "이 회사는 국내라 괜찮다"로 뭉뚱그리지 마세요.

## 3. "즉시 파기" 문구 주의

동의서에 "분석 완료 후 즉시 파기"라고 쓰려면, **기관 보관본의 파기**와
**AI 제공사의 보관 기간**(예: API 로그 기본 30일)을 구분해서 고지해야 합니다.
구분 없이 쓰면 당사자는 "AI 회사에서도 즉시 지워진다"로 읽습니다 — 허위 고지가 됩니다.

## 4. "AI 학습에 사용되지 않습니다" 문구의 조건

이 문구는 기업용 API/서비스를 쓰거나 학습 옵트아웃을 설정한 경우에만 참입니다.
무료 소비자용 챗봇을 기본 설정으로 쓰면서 이 문구를 유지하면 허위 고지입니다.

## 5. 인공지능기본법 제31조는 아무 데나 인용하지 말 것

제31조(사전 고지)의 수범자는 "이용자에게 AI 제품·서비스를 **직접 제공**하는
인공지능사업자"로 안내되고 있습니다.
- 직원이 업무 보조로 AI를 쓰는 것(상담 요약 등) → 대상이 아닐 가능성이 높음.
  이때의 안내는 "법정 의무"가 아니라 "기관 자율 고지"로 표기.
- 이용자가 직접 쓰는 챗봇을 배포 → 명확히 대상. 화면에 AI 기반임을 고지.
- 계도기간(과태료 유예)이 운영 중이더라도 의무 자체는 시행일부터 발생해 있고,
  민사 책임의 방패가 되지 않는다는 해석이 있으니 "계도기간이니 미뤄도 된다"고 쓰지 말 것.

## 6. 앱을 만들면 처리방침을 갱신하라

새 앱 = 새 수탁자(예: Supabase, Inc.)일 수 있습니다. 확인 목록:
- [ ] 처리방침의 수탁자/국외이전 목록에 추가했는가
- [ ] 벤더 DPA에 서명했는가 (Supabase는 대시보드에서)
- [ ] 수탁자 1곳 원칙(guide.md)을 지켰는가 — 저장소가 늘수록 이 문서도 늘어난다
- [ ] 홈페이지가 없는 소규모 기관: 기관 내 게시·서면 비치·신청서 별지로도 공개 의무 충족 가능
