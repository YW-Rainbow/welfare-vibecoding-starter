> 같은 리포의 glossary.md 풀이로 통역하세요.

> 사용법: 이 파일을 AI 대화에 첨부하고 "이 규칙을 지켜서 코딩해줘"라고 지시하세요.
> 적용 대상: **N등급(개인정보 없음)** 앱만 — 안내, 계산기, 익명 집계 대시보드, 재고 관리 등.
> 스택: Pages(프론트) + Workers(API) + D1(DB) + R2(파일). 월 $0~5.
> 기준일: 2026-08

## 최우선 규칙: 등급 이탈 감시

- 이 스택은 개인정보가 없다는 전제로 성립한다. 개발 중 요구사항에
  **이름·연락처·식별 가능한 사진**이 들어오는 순간, 코딩을 멈추고
  guide.md의 판정 트리를 다시 태운다 (대개 경로 A로 이사).
- "익명"이라던 데이터가 사실 식별 가능한 경우를 경계한다
  (예: 소규모 기관의 "연령+동네+프로그램" 조합은 식별 가능할 수 있다).

## 보안 기본

1. API 키·토큰은 `wrangler secret`으로만. 코드·공개 저장소에 하드코딩 금지.
   `.dev.vars`는 `.gitignore`에 반드시 포함.
2. CORS는 자기 도메인만 허용. `Access-Control-Allow-Origin: *` 금지.
3. 쓰기 엔드포인트(POST/PUT/DELETE)에는 최소한의 보호(토큰 또는 Cloudflare Access)를 건다.
   "공개 데이터니까 쓰기도 열어두자"는 스팸·변조 경로다.
4. D1 쿼리는 반드시 바인딩(`?` 파라미터) 사용. 문자열 조합 SQL 금지.

## 직접 만들어야 하는 것 (이 스택의 숙제 — 매트릭스 △ 항목)

이 스택은 벤더가 해주는 게 적다. 다음을 코드·절차로 채우고 있는지 확인하라:

1. **백업**: D1은 자동 백업에 의존하지 말 것. `wrangler d1 export`를 주기 실행(GitHub Actions
   스케줄 등)해서 SQL 덤프를 별도 위치에 보관하는 절차를 만들고 문서화한다.
2. **관리 화면**: D1에는 시트 같은 UI가 없다. 최소한의 읽기 전용 관리 페이지
   (테이블 조회·CSV 내보내기)를 함께 만들어라 — 후임자가 데이터를 눈으로 볼 수 있어야 한다.
3. **인계 문서**: wrangler 로그인 계정(기관 공용으로), 배포 명령, 도메인 설정을
   `ops/handover.md` 체크리스트로 남긴다.

## 비용·한도

- 무료 한도(Workers 일 10만 요청, D1·R2 용량)는 초과 시 **멈추는** 안전한 실패다.
  다만 대시보드에서 사용량 알림을 켜두고, 한도가 일상적으로 차기 시작하면
  Paid($5/월) 전환 또는 설계 재검토.
